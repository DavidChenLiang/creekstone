# creek stone

Brand wordmark and usage guide for a small systems studio.

Live page: https://davidchenliang.github.io/creekstone/

## Files

| File | Use |
|---|---|
| `creekstone-wordmark-ink.svg` | Primary wordmark, light background |
| `creekstone-wordmark-cream.svg` | Primary wordmark, dark background |
| `creekstone-wordmark.svg` | currentColor version, follows CSS colour |
| `creekstone-stacked-ink.svg` / `-cream.svg` / `.svg` | Square lockup, avatars and cards |
| `mark-c-ink-solid.svg` / `-ink.svg` / `-transparent.svg` | Single-letter mark, for 32 px and below only |
| `favicon.ico` / `icon-180.png` | Site favicon and touch icon |
| `sheet.png` / `guide.png` / `inuse.png` | Presentation sheets |
| `guide.html` / `inuse.html` | Editable web sources |
| `index.html` | Landing page (GitHub Pages) |

## Spec

- Letter spacing `0.010em` · word gap `0.115em` · stacked leading `0.80em`
- Ink `#14161A` · Paper `#F7F5EF`
- Minimum wordmark width **32 px**; 180 px recommended
- Clear space: at least one mark height on all sides
- Do not stretch, outline, shadow, re-track, or place on patterns

All lettering is converted to outlines — no font dependency.
